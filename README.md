# chrome-darkmode

## Install

1. Download `dusk-<version>-chrome.zip` from the [latest release](https://github.com/tuurbo/chrome-darkmode/releases/latest) and unzip it to a folder you will keep.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and choose the unzipped folder.

Chrome runs the extension from that folder, so don't delete or move it.

## Update

Chrome does not update unpacked extensions on its own.

1. Download the new zip, empty the extension's folder, and unzip the new files into it.
2. Open `chrome://extensions` and click the reload button on Dusk.

Use the same folder each time. Chrome ties your site settings to the folder's location, so loading a copy from somewhere else starts with no settings.
